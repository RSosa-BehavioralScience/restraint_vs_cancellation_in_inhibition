# restraint_vs_cancellation_in_inhibition
Contains R code and data for testing dissociations between response restraint and cancellation in inhibitory control paradigms. Methods for exploring, testing, and quantifying dissociation are described in "Dissociating Response Restraint and Response Cancellation Facets of Inhibitory Control Using a Pavlovian Protocol".

## Accessing the nested compressed files

The compressed files are in .rar format, which may require a program such as 7-Zip to open. Some programs show the contents of a compressed file without decompressing it, but they may not show what is inside a compressed file that is itself inside another one. To reach every file:

1. Decompress the outer file completely.
2. Decompress each inner file in turn.

Alternatively, each inner file can be downloaded separately from this repository.

## Instructions for Data Processing and Analysis Pipeline

1. Load required packages
2. Import the dataset using `load`
3. Run analysis scripts in the specified sequence
4. Save your workspace periodically to preserve progress
5. If interrupted, reload your saved environment
